# 斗地主 · 联网对战 App

双人 / 三人斗地主，支持真人对战与人机对战，附带私信、语音、表情包与私密空间。

---

## 一、功能一览

| 模块 | 说明 |
|---|---|
| 三人斗地主 | 54 张经典规则，叫分抢地主，农民一方出完即胜 |
| 双人斗地主 | 两套玩法：`让牌玩法`（46 张，抢地主让牌）与`经典玩法`（54 张） |
| 人机对战 | 机器人由服务端托管，名字、头像、思考时长与真人一致，牌桌上无法分辨 |
| 创建房间 | 可选「双人 / 三人」×「真人对战 / 人机对战」，生成房号发给好友 |
| 混战组合 | 三人房支持 2 真人 + 1 机器人、1 真人 + 2 机器人，可随时补机器人或移除机器人 |
| 账号 | 每次登录随机生成新昵称与新头像，账号身份（UID）保持不变 |
| 私信 | 文字、语音、图片、视频、文件、表情包；会话与单条消息均支持长按删除 |
| 表情包 | 24 个手绘 SVG 贴纸 + 140 个 Emoji |
| 私密空间 | 4 位数字暗号，入口为「我的」页连击 UID 5 次，无任何图标/按钮暴露 |
| 隐私伪装 | 通知栏与主界面只显示斗地主营销广告，真实消息仅在私密空间可见 |
| 战绩 | 自动保存，可单条删除或一键清空 |

## 三、部署到服务器（国内免费主机）

完整图文步骤见 **《服务器开通与部署指南.md》**（注册 → 实名 → 开机 → 放行端口 → 上传 → 一键部署 → 验证）。

这里只列要点：

### 1. 选主机

推荐阿贝云 https://www.abeiyun.com 或三丰云 https://www.sanfengyun.com，免费、不用信用卡。
注册只需**手机号 + 实名认证（0.3 元）**。

⚠️ **注意**：这两家的"永久免费"是**用发帖换时长**——阿贝云每 5 天、三丰云每 1~5 天需在官方论坛发一篇体验帖申请续期。觉得麻烦可直接买最低配付费机（1核2G 约 30~40 元/月）。

开通时**系统必须选 Linux**，推荐 Ubuntu 22.04（Windows 系统跑不了部署脚本）。

### 2. 放行端口

服务跑在 **8080**，需在控制台「安全组 / 防火墙」放行 TCP 8080，来源 `0.0.0.0/0`。
（国内服务器 80/443 需备案才能访问，所以别用 80。）

### 3. 上传并部署

把 `ddz` 目录传到服务器 `/root/`，然后：

```bash
cd /root/ddz
chmod +x deploy/deploy.sh
sudo bash deploy/deploy.sh 8080
```

脚本自动完成：安装 Node 20 → 拷贝文件 → 装依赖 → 配置开机自启 → 放行端口 → 健康检查。

### 4. 验证

```bash
curl http://127.0.0.1:8080/api/health     # 返回 {"ok":true,...} 即正常
```

浏览器打开 `http://你的IP:8080` 能看到游戏界面即成功。

**运维命令**

```bash
systemctl status ddz      # 查看状态
journalctl -u ddz -f      # 实时日志
systemctl restart ddz     # 重启
```

数据保存在 `/opt/ddz/data/db.json`，免费机会停机，定期备份该文件。

## 四、编译安卓安装包（GitHub Actions，无需安装 Android Studio）

### 1. 准备代码仓库

1. 注册 GitHub 账号（https://github.com）
2. 新建仓库（New repository），名字随意，例如 `ddz-app`
3. 把 `ddz` 目录上传到仓库：

```bash
cd ddz
git init
git add .
git commit -m "斗地主 App"
git branch -M main
git remote add origin https://github.com/你的用户名/ddz-app.git
git push -u origin main
```

### 2. 触发编译

1. 打开仓库页面 → 顶部 **Actions**
2. 左侧点击 **「编译安卓安装包」**
3. 右侧点 **Run workflow**（运行工作流）
4. 填写两个参数：
   - `server_url`：你的服务器地址，例如 `http://123.45.67.89:8080`
   - `app_name`：App 名称，默认「斗地主」
5. 点绿色 **Run workflow** 按钮
6. 等 5~10 分钟，状态变绿后，在页面底部 **Artifacts** 区域点击 **「斗地主-安装包」** 下载

下载得到 `app-debug.apk`，传到手机点击安装即可。

> 手机安装时若提示「未知来源」，允许一次即可。
> 换服务器地址后，重新运行一次 workflow 即可生成新包。

### 3. 本地编译（可选）

如果电脑上已装 Android Studio：

```bash
npm install
APP_SERVER=http://你的IP:8080 npm run build:www
npx cap add android
npx cap sync android
cd android && ./gradlew assembleDebug
```

产物：`android/app/build/outputs/apk/debug/app-debug.apk`

## 五、私密空间说明

**入口**：进入「我的」页面 → **连续点击 UID 那行文字 5 次**（间隔不超过 0.9 秒）。

页面上 UID 只是一串普通灰字，没有图标、没有按钮、没有菜单，「我的」页面里也找不到任何「私密空间」字样，旁人看不出它是入口。

**暗号流程**

| 场景 | 表现 |
|---|---|
| 首次进入 | 显示「首次进入，请设置 4 位暗号」+ 4 个暗点，系统数字键盘自动弹出，输满 4 位即设置成功 |
| 之后进入 | 界面**完全无变化**，不出现任何 PIN 输入控件，只弹出系统输入法数字键盘；输满 4 位自动进入私密空间 |
| 暗号错误 | 不提示「暗号错误」，而是弹一条随机斗地主营销广告，看不出发生了什么 |

输入控件是一个 1×1 像素、完全透明的 `input[type=text][inputmode=numeric][pattern=[0-9]*]`，
只用于唤起手机系统数字键盘并接收输入，界面上不可见。中途收起键盘则静默取消。

> 桌面浏览器没有数字键盘，可直接在页面任意处输入 4 位数字（输入框保持隐藏聚焦）。

**修改暗号**：私密空间内「修改暗号」→ 输入新的 4 位数字。

**消息删除**（主界面聊天）

- **长按会话列表里的某人** → 确认后删除与该联系人的整个会话，聊天记录全部清除
- **长按会话内某条消息** → 弹出菜单，可选「删除这条消息」或「清空整个会话」

删除对双方同时生效，删除后联系人列表自动刷新。

**紧急退出**（私密空间开着时才生效）

| 操作 | 效果 |
|---|---|
| 锁屏 / 按 Home 键 / 切后台 | 立即关闭私密空间，App 最小化，再次打开直接回到大厅主界面 |
| 摇一摇手机 | 立即关闭私密空间并跳回大厅主界面（10ms 短震动反馈） |

主界面（大厅 / 对战 / 聊天 / 我的 / 创建房间）**不包含任何「私密」「隐私模式」「指定入口」等字样**，登录页副标题也做了中性化处理，旁人翻遍界面也看不出存在隐藏空间。

## 六、隐私伪装说明

- 开启后（默认开启）：手机通知栏收到的是随机斗地主营销广告，例如「🎁 每日福利已到账 · 登录即领 8888 欢乐豆」
- 主界面聊天列表与会话内同样只显示广告文案，**界面上不会出现任何「已隐藏」「私密空间可见」之类的提示语**
- 好友上线 / 收到新消息，通知栏推送的都是随机广告，不会出现「xx 已上线」
- 真实消息进入 **🔒 私密空间** 才能看到
- 「我的」页面可随时关闭该开关

## 八、常见问题

**Q：三人房能两个真人加一个机器人吗？**
A：可以。创建三人「真人对战」房间 → 好友输入房号加入 → 点「机器人加入」即自动开局。也可以自己连点两次「机器人加入」变成 1 真人 + 2 机器人；等待界面还能「移除机器人」把座位腾给好友。

**Q：暗号能不能在登录时就强制设置？**
A：默认是「首次进入私密空间时设置」，这样登录流程不会暴露私密空间的存在。
如需改成登录即设置，把 `secret.js` 里 `enter()` 改为登录后自动调用一次即可。

**Q：机器人会不会很明显？**
A：机器人有 0.6~2 秒的思考延迟，会犹豫、会偶尔犯错，叫分也会「手滑」，昵称头像同样是随机生成的，牌桌 UI 上没有任何 AI 标识。

**Q：三人局两个人都不叫分怎么办？**
A：会重新发牌。机器人有兜底策略，流局概率约 2%。

**Q：服务器重启后数据还在吗？**
A：在。数据存在 `/opt/ddz/data/db.json`，且服务配置了开机自启。

**Q：想换服务器地址？**
A：重新运行 GitHub Actions 工作流，填入新地址即可，不需要改代码。
